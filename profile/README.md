We build open-source software and projects for developers at [upset.dev](https://upset.dev), focused on infrastructure, networking, and developer tools. Here are some of the projects we're working on.

### Platform

**[Pyo](https://github.com/upsetdev/pyo)** is an open-source, self-hosted PaaS for deploying and managing applications on your own infrastructure. Run it on a single server or across an entire cluster.

Explore [pyo.dev](https://pyo.dev), the [documentation](https://github.com/upsetdev/pyo-docs), and the [templates](https://github.com/upsetdev/pyo-templates).

### APIs and projects

- **[favicone](https://github.com/upsetdev/favicone)** - Fetch the favicon of any website. [favicone.com](https://favicone.com)
- **[dns-profile-generator](https://github.com/upsetdev/dns-profile-generator)** - Generate encrypted DNS profiles for Apple devices.
- **[fonts.upset.dev](https://github.com/upsetdev/fonts.upset.dev)** - A privacy-friendly proxy for Google Fonts.
- **[stak](https://github.com/upsetdev/stak)** - Visualize Kubernetes and Docker Compose configurations as topology maps.
- **[edns](https://github.com/upsetdev/edns)** - Identify your DNS resolver and its EDNS Client Subnet (ECS).
- **[whoami](https://github.com/upsetdev/whoami)** - Get information about your IP address, location, network, and browser.
